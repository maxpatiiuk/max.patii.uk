I took part in a one-on-one conversation with a member of the Google Project
Fugu Team.

Project Fugu is focused on extending web capabilities and bridging the gap
between native apps and PWAs.

We talked about the possibility of utilizing the WebGPU API, Storage API, WebHID
API, and Window Placement API to create a cross-platform, browser-based video
editing solution. We also expressed our opinions on the possibility of
browser-based operating systems (like Chrome OS) replacing the need for a
Windows or macOS system for professional work that relies on low-level access to
the CPU/GPU.

Besides that, I was invited to attend a two-day JavaScript & Accessibility
Workshop. The workshop was limited to 100 participants selected as part of the
application process.

2026 update: A blog post inspired by what I learned:
